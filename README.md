# Priscilla-movie-page-html-css

🎬 Priscilla Movie Page

A simple and aesthetic fan page dedicated to Priscilla (2023), created as a front-end practice project using HTML and CSS.

The goal of this project was to practice building a complete web page from scratch while working with page structure, layouts, images, navigation, tables, links, and responsive design.

🌸 Preview

The website contains information about the movie Priscilla, including:

* 🎞️ Movie introduction
* 🎭 Cast information
* 📖 Movie plot
* ✨ Interesting facts
* 🎬 Recommended movies
* 💌 Contact information
* 🔗 External links
* 📱 Responsive layout for smaller screens

🛠️ Technologies

* HTML5
* CSS3
* Flexbox
* CSS Media Queries
* Git & GitHub

🎨 Design

The page uses a soft, vintage-inspired aesthetic with:

* Pastel colors
* Rounded sections
* Decorative typography
* Movie photography
* Simple navigation
* Structured content sections

The layout was designed to work on both desktop and mobile devices.

📱 Responsive Design

A responsive layout was implemented using CSS media queries so that the page adapts to smaller screen sizes.

On mobile devices:

* Navigation links wrap when necessary
* Images scale to fit the screen
* Content sections stack vertically
* Tables adapt to smaller widths
* Horizontal overflow is prevented
